# Tenant asset files live here and are served at `/assets/*` by the API.

Drop these two files in THIS folder (exact names matter):

- `tcet-watermark.png` — the TCET shield logo (used as the every-page watermark)
- `tcet-header.png` — the department banner (used as the every-page header)

Until they exist, the HTML preview renders styled placeholders in the same
positions so layout can be reviewed without the artwork.
